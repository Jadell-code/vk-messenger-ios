# Запрос доступа к messages API

Готовое письмо для `devsupport@corp.vk.com`. Отправлять с почты, привязанной к
бизнес-профилю VK ID.

## Тема

Запрос доступа к messages API для приложения VK ID 54882991

## Текст

Здравствуйте.

Меня зовут Слюсарь Денис Андреевич. Я разработчик нативного iOS-клиента
для работы с сообщениями ВКонтакте.

Приложение VK ID: **54882991** («Messenger iOS»), платформа Web, бизнес-профиль
подтверждён. Авторизация VK ID 2.1 с PKCE уже работает: обмен кода на токен,
`id.vk.ru/oauth2/user_info` и `users.get` проходят успешно. Вход через VK ID
реализован и в нативном iOS-приложении (`WKWebView` + PKCE).

При вызове `messages.getConversations` с токеном VK ID возвращается ошибка:

```
VK API 1051: Method is not available for this profile type:
method is unavailable with current profile type
```

Запрос `scope=messages` в `id.vk.ru/authorize` принимается формой согласия, но в
токене остаётся только `vkid.personal_info`.

Прошу предоставить приложению 54882991 доступ к методам:

- `messages.getConversations`
- `messages.getHistory`
- `messages.send`
- `messages.markAsRead`
- `messages.setActivity`
- `messages.getLongPollServer` / LongPoll

Приложение — нативный клиент для личной переписки пользователя. Оно не рассылает
спам, не работает с чужими аккаунтами и не автоматизирует действия без участия
пользователя. Токен хранится в Keychain на устройстве, серверной части нет.

Если доступ к `messages` для новых приложений VK ID не выдаётся, подскажите,
пожалуйста, официальный способ интеграции мессенджера или партнёрскую программу,
в рамках которой такой доступ возможен.

С уважением,
Слюсарь Денис Андреевич
```

## Что приложить

- скриншот раздела «Доступы» приложения 54882991;
- скриншот ошибки 1051 из `scripts/vk-id-exchange.ps1`;
- ссылку на репозиторий (если он публичный): `https://github.com/Jadell-code/vk-messenger-ios`.

## Реалистичная оценка

VK исторически не выдаёт новым сторонним клиентам доступ к личным сообщениям.
Вероятность одобрения низкая. Ответ может занять несколько дней. Пока идёт
ожидание, приложение остаётся в демо-режиме.
